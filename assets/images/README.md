## Image Optimization Tips

- Compress images to reduce file size without losing quality
- Use appropriate formats: PNG for logos with transparency, JPG for photographs
- Ensure images are high quality but web-optimized (under 500KB each if possible)
- Maintain aspect ratio to prevent distortion

## Note

The website will display placeholder backgrounds if images are missing. Once you add the images to this folder, they will automatically appear on the website.
